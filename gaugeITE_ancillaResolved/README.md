# GaugeITE

`GaugeITE` is a Qiskit package for ancilla-resolved imaginary-time simulation
of transverse-field Ising models. It builds the circuits, retains every
ancilla outcome, converts the measured records into gauge-flux classes, and
computes class-conditioned thermodynamic quantities.

The package supports:

- exact-Kraus and linear elementary-angle mappings;
- one or more imaginary-time steps;
- coherent-reuse, fresh-trajectory, and measure-reset circuits;
- gauge-class classification from cycle or plaquette fluxes;
- class probabilities and class-conditioned energies;
- exact-diagonalization references and quenched free-energy reconstruction;
- local Aer simulation and optional IBM Quantum execution.

## Installation

Clone the repository and install the package:

```bash
python -m pip install -e .
```

Aer is installed with the package. For IBM Quantum support, use:

```bash
python -m pip install -e ".[ibm]"
```

## Basic simulation

```python
from gauge_ite import (
    ExecutionConfig,
    GaugeITEExperiment,
    ITEProtocol,
    TFIMSpec,
)

spec = TFIMSpec.rectangular(rows=2, cols=2)
protocol = ITEProtocol(
    beta=0.75,
    steps=1,
    angle_mapping="exact_kraus",
    architecture="coherent_reuse",
    input_mode="purification",
)
execution = ExecutionConfig(provider="aer", shots=4096, seed=2026)

result = GaugeITEExperiment(spec, protocol, execution=execution).run(
    "class_probabilities"
)

print(result.classes)
```

Normal runs stay in memory. Save a run only when needed:

```python
result.save("runs")
```

## Gauge-class information

Each ancilla bitstring is converted into term signs, bond signs, cycle
fluxes, plaquette fluxes, and a gauge-class identifier.

```python
trajectory = ITEProtocol(
    beta=0.75,
    steps=2,
    architecture="fresh_trajectory",
    input_mode="purification",
)
result = GaugeITEExperiment(spec, trajectory, execution=execution).run(
    "trajectory_records"
)

print(
    result.analysis["branches"][[
        "ancilla_bitstring",
        "class_ids_by_step",
        "plaquette_fluxes_by_step",
        "persistent_signs",
        "probability",
    ]]
)
print(result.analysis["classes"])
```

A persistent record is a fresh or measure-reset trajectory whose complete
sign vector stayed unchanged at every step. For multi-step coherent reuse,
only the final record is measured, so persistence is deliberately left
undefined.

## Class-conditioned energy

Energy estimation runs the circuit in the system Z and X measurement bases.
The system outcome remains paired with its ancilla record so every sample can
be assigned to the correct gauge class.

```python
energy_result = GaugeITEExperiment(
    spec,
    protocol,
    execution=execution,
).run("energy")

print(energy_result.analysis["class_energies"])
print(energy_result.analysis["direct_unconditioned_energy"])
```

## Exact class thermodynamics

```python
from gauge_ite.thermodynamics import exact_class_thermodynamics

class_table = exact_class_thermodynamics(
    TFIMSpec.rectangular(2, 3),
    beta_values=(0.0, 0.25, 0.5, 0.75, 1.0),
)
print(class_table)
```

The table includes the class flux label, ground-state energy, Gibbs energy,
partition function, multiplicity weight, and annealed class weight.

## Quenched free-energy reconstruction

```python
import numpy as np

from gauge_ite import QuenchedFreeEnergyStudy, TFIMSpec

study = QuenchedFreeEnergyStudy(
    spec=TFIMSpec.rectangular(2, 3),
    beta_values=np.linspace(0.0, 1.4, 29),
    shots_per_basis=4096,
)
quenched = study.run()
print(quenched["summary"])
```

This reconstructs class partition functions by thermodynamic integration and
keeps the fixed quenched prior separate from the temperature-dependent class
distribution generated by the circuit.

## Command line

```bash
# Class probabilities on Aer; no files are written.
gauge-ite run --rows 2 --cols 2 --beta 0.75 --shots 4096

# A two-step fresh trajectory.
gauge-ite run --rows 2 --cols 2 --steps 2 \
  --architecture fresh_trajectory --observable trajectory_records

# Class-conditioned energy from Z- and X-basis runs.
gauge-ite run --rows 2 --cols 2 --observable energy

# Add --save only when the circuits, counts, and tables should be retained.
gauge-ite run --rows 2 --cols 2 --observable energy --save
```

## IBM Quantum

Save an IBM Runtime profile from a hidden terminal prompt:

```bash
gauge-ite configure ibm --profile default
```

Then submit to the least-busy compatible backend:

```bash
gauge-ite run --provider ibm --profile default --backend auto \
  --rows 1 --cols 2 --shots 4096 --submit
```

The `--submit` flag is required before a real hardware job is sent. API tokens
are stored by Qiskit Runtime and are never placed in the source code.

## Examples

- quenched free-energy reconstruction; and
